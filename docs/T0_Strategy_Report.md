# T+0 日内择时策略研究报告

**研究标的**：中证1000成分股（约1000只）  
**数据频率**：5分钟K线（每日约48根bar，09:30~15:00）  
**持有周期**：30分钟（6根bar）  
**测试区间**：2024年训练，2025年全年测试（样本外）

## 一、因子体系

全部特征共 **31个**，按来源分为三大类，均经过跨日同时刻标准化处理后输入模型。

### 1.1 经典技术指标类（16个）

| 因子名 | 含义 |

| `dif_std` | DIF的短期波动率 |
| `dea_std` | DEA的短期波动率 |
| `macd_std` | MACD柱的短期波动率 |
| `kdj_k` | KDJ指标K值（RSV的EMA平滑） |
| `kdj_d` | KDJ指标D值（K值的EMA平滑） |
| `kdj_j` | KDJ指标J值 = 3K − 2D，超买超卖指标 |

## 二、因子标准化与 IC 计算

### 2.1 标准化流程（严格无未来函数）

标准化在**时间序列维度**进行（非截面），核心思想：

> 今天 09:40 的标准化参数 = 过去20个交易日 09:40 的历史统计量。

这样不同时刻（如开盘集合竞价后 vs 尾盘）的因子分布差异被消除，且严格无前视。

**具体步骤（对每个因子）**：

```
步骤1 — 去极值（2倍MAD）:
  历史中位数 med = rolling(20, shift=1).median()
  MAD近似    = 0.6745 × rolling(20, shift=1).std()
  Winsorize  = clip(raw, med − 2×MAD, med + 2×MAD)

步骤2 — Z-score标准化:
  hist_mean  = rolling(20, shift=1).mean()
  hist_std   = rolling(20, shift=1).std()
  norm       = (winsorized − hist_mean) / hist_std
```

**实现效率**：对每个因子做一次全市场 pivot（行=date，列=(SecuCode, time)），一次 rolling 计算所有股票所有时刻，消除逐股票循环，处理1000只股票约1~2分钟。

### 2.2 未来收益率定义

```
买入价 = 信号bar(t) 的下一根bar(t+1) 的 VWAP
卖出价 = bar(t+1+6) 的 VWAP           （持有6根bar = 30分钟）
原始收益 = 卖出VWAP / 买入VWAP − 1
fwd_ret_30min = 原始收益 − 15 bps     （含单次双边成本）
```

使用 **bar VWAP**（= amount/volume）而非 open/close：比点价更难被滑点影响，更接近实盘平均成交价。

### 2.3 时序 IC（核心评估指标）

T+0策略评估的是**单只股票日内择时能力**，因此使用时序IC，而非跨股票的截面IC。

**定义**：对每个 (SecuCode, date) 组合（约48根bar），计算因子值序列与未来收益率序列的 Spearman 相关系数，再按日期取均值。

```
时序IC(t) = mean over stocks { Spearman(factor[s,t], fwd_ret[s,t]) }
ICIR      = mean(时序IC) / std(时序IC)
```

**全向量化实现**（84× 加速，与逐组 scipy.spearmanr 结果偏差 < 1e-16）：

```python
# 组内rank后，Pearson = Spearman
pred_rank = df.groupby(["SecuCode","date"])["pred"].rank(pct=True)
ret_rank  = df.groupby(["SecuCode","date"])[ret_col].rank(pct=True)
# 全向量化 Pearson = sum(dx·dy) / sqrt(sum(dx²)·sum(dy²))
# 通过 groupby.transform("sum") 一步完成，无任何 Python 层 apply 回调
```

**非重叠采样**：为避免相邻bar的未来收益窗口重叠（导致标签自相关），IC评估前对每个 (SecuCode, date) 组随机选起始偏移，每隔6根bar取1个样本。

## 三、目标变量分布统计（全量样本实证）

> 数据来源：中证1000成分股，2024全年（训练集）+ 2025全年（测试集），约2320万行有效bar。  
> 以下统计均基于**扣除15bps成本后的净收益**（即模型实际预测目标 `fwd_ret_*min`）。

### 3.1 核心发现：原始价格收益接近随机游走

| 持有期 | 原始价格收益均值 | 扣cost后均值 | 标准差 | 多头胜率 |
|--------|--------------|------------|--------|---------|
| 15min  | +0.14 bps    | −14.86 bps | 56.79 bps | 46.4% |
| 30min  | +0.17 bps    | −14.83 bps | 79.91 bps | 46.0% |
| 45min  | +0.11 bps    | −14.89 bps | 97.03 bps | 45.7% |
| 60min  | +0.06 bps    | −14.94 bps | 111.53 bps | 45.6% |

**关键结论**：原始价格收益（未扣成本）均值仅 **+0.06 ~ +0.17 bps**，接近于 0，说明 A 股 5 分钟级别的短期价格变动在**方向上是随机游走**，不存在系统性漂移。标准差随持有期延长而线性放大（约 56→112 bps），符合布朗运动的 $\sigma \propto \sqrt{T}$ 规律。

**扣除 15 bps 双边成本后，全样本均值约 −14.9 bps**：这意味着对任意一根 bar 随机开仓，期望净亏 15 bps/笔，交易成本完全吞噬了价格漂移，无差别频繁交易必然亏损。这也是 T+0 策略必须依赖**择时因子**来识别少数高概率方向窗口的根本原因。

### 3.4 关键统计解读

- **偏度持续为正（+1.6 ~ +2.4）**：收益分布右偏，存在少量大幅上涨的 bar（正向肥尾），但中位数低于均值，典型的"多空不对称"结构。做多有小概率获得大收益，但整体概率不利。

- **峰度极高（14 ~ 37）**：远超正态分布（峰度=3），说明极端收益事件频发，波动在绝大多数时刻集中，但偶发暴涨暴跌。持有期越短，峰度越高（2025年15min峰度高达34.6）。

- **2025年波动率整体低于2024年**：2025年各持有期标准差均比2024年低约6~15bps，整体市场波动性降低，但偏度和峰度更高，说明2025年行情特征是"平静期偶发极端波动"。

- **成本信噪比**：成本（15bps）/ 标准差：15min为26.4%，60min为13.5%。持有期越长，成本占波动的比例越低，理论上**信噪比**随持有期延长而改善——但同期噪声也在增大，模型可预测性下降。本策略选择30min（6根bar）是在成本信噪比与模型预测衰减之间的折中。

## 四、LightGBM 模型训练

### 4.1 整体框架

| 项目 | 配置 |
|------|------|
| 模型类型 | LightGBM 回归（预测 `fwd_ret_30min`） |
| 输入特征 | 31个 `_norm` 标准化特征 |
| 训练集 | 2024年全年（约240个交易日 × 1000只股票 × 48bar） |
| 测试集 | 2025年全年（样本外，完全不参与训练） |
| 切分方式 | 严格按日期时序，无随机shuffle |

### 4.2 Walk-Forward 标签（关键设计）

训练标签的构建也采用严格无前视的 Walk-Forward 方式，避免当天组内排名依赖未来bar信息：

```
D日某bar的label = D日fwd_ret在历史 [D-10, D-1] 同一时刻（HH:MM）分布中的经验百分位
```

具体实现：对每个 (SecuCode, time_of_day) 组合，用过去10天同一时刻的 `fwd_ret` 序列，计算10分位阈值，判断当天该时刻的收益落在历史分布的哪个百分位段（0~1之间）。

这使得**训练label与回测信号触发逻辑完全对称**——训练时学习的是"收益在历史分布中的相对位置高低"，回测时也是用历史 pred 分布的分位数阈值来触发信号。

### 4.3 训练参数

```python
LGBM_PARAMS = {
    "objective":        "regression",
    "metric":           "rmse",
    "n_estimators":     1000,       # 固定轮数（收益噪声大，RMSE无法有效early stop）
    "learning_rate":    0.05,
    "num_leaves":       63,
    "min_child_samples":200,        # 防过拟合，叶节点最小样本数
    "feature_fraction": 0.7,        # 每棵树随机选70%特征
    "bagging_fraction": 0.8,        # 每轮随机采样80%样本
    "bagging_freq":     5,
    "lambda_l1":        0.1,
    "lambda_l2":        1.0,        # L2正则
    "n_jobs":           64,
}
```

### 4.4 评估指标

训练完成后计算以下指标，均在**非重叠采样**的测试集上：

| 指标 | 说明 |
|------|------|
| **时序日均IC** | 测试集各日时序IC的均值，核心指标 |
| **ICIR** | 时序IC均值/标准差，衡量IC稳定性 |
| **IC>0比例** | 时序IC为正的交易日占比 |
| **IC Gap** | 训练集IC − 测试集IC，>0.1 触发过拟合预警 |
| **pred分层单调性** | 按pred分10层，验证各层fwd_ret是否单调递增 |

**过拟合控制**：使用 `min_child_samples=200`（大叶节点约束）+ L2正则，训练集IC与测试集IC差距作为监控指标。

## 四、回测框架

### 4.1 整体流程

```
原始预测结果（pred）
    ↓
Walk-Forward阈值计算（历史滚动分位数，按SecuCode×time_of_day分组）
    ↓
信号生成（pred超过历史极端分位 → 触发做多/做空）
    ↓
冷却期过滤（同一股票同日内相邻信号间隔 ≥ 6根bar）
    ↓
按日聚合等权收益 → 计算绩效指标
```

### 4.2 Walk-Forward 信号触发（无前视偏差）

回测中的信号触发逻辑与实盘完全一致，**严格不使用当天全部bar做事后排名**：

```
对每只股票的每个时刻 (SecuCode, HH:MM)：
  滚动窗口 = 过去10个交易日同一时刻的 pred 值
  做多阈值 threshold_long  = rolling(10).quantile(0.95).shift(1)
  做空阈值 threshold_short = rolling(10).quantile(0.05).shift(1)

触发规则：
  pred(t) > threshold_long  → 做多信号
  pred(t) < threshold_short → 做空信号
```

`shift(1)` 确保 D 日触发信号时，阈值只基于 D-1 日及以前的历史数据。前10个交易日为预热期，不触发信号。

### 4.3 成本处理

`fwd_ret_30min` 在计算时已扣除一次15bps双边成本，因此回测中：

```
做多单笔净收益 = fwd_ret_30min
                = 价格收益 − 15bps         （即直接使用）

做空单笔净收益 = −(fwd_ret_30min + 15bps) − 15bps
                = −价格收益 − 15bps        （还原后重新扣一次完整成本）
```

### 4.4 冷却期过滤

为避免同一持有期窗口内出现重叠仓位，对每只股票每天的信号列表做**贪心过滤**：
- 相邻两笔信号的bar间距 ≥ 6根bar（= 1个持有期）
- 全向量化 numpy 实现，处理50万+ 信号约5秒

### 4.5 绩效指标体系

| 指标 | 公式/说明 |
|------|----------|
| 年化收益率 | 日均收益 × 252 |
| 夏普比率(SR) | 年化收益 / 年化波动率 |
| 最大回撤(MDD) | 累计收益曲线的最大回撤 |
| 卡玛比率(Calmar) | 年化收益 / MDD |
| 日度胜率 | 当日收益 > 0 的比例 |
| t-stat | 均值显著性检验，>2 视为统计显著 |

## 五、训练标签方案对比实验

基于相同特征集（31个`_norm`特征）、相同数据切分（2024训练/2025测试）、相同LGBM参数，对三种训练标签方案进行横向对比，评估指标均在**非重叠采样的样本外测试集**上计算。

### 5.5 结论

1. **原始fwd_ret直接回归失败**：测试IC=-0.059，方向反转，完全无法泛化。根本原因是绝对收益率均值接近0（约-14bps），方差极大，跨年度分布漂移严重，模型只是在拟合训练期的噪声模式。

2. **WF标签版是最优训练框架**：测试IC=0.040，t-stat=5.86～7.23，统计显著。相对分位标签对绝对量级不敏感，跨年度泛化能力明显更强。

3. **当前alpha瓶颈**：WF版模型的多空spread约3~4bps，低于双边成本20bps（=10bps双边×2方向），导致策略整体亏损。**瓶颈不在训练方式，而在特征信息量**——现有31个技术指标特征的预测上限约8~9bps，需要引入订单流（OFI）等微观结构特征来突破。

4. **持有期影响**：15min持有期的分层spread t-stat（7.23）优于30min（5.86），说明模型短期预测能力稍强；但回测中15min因持有期更短、绝对收益幅度更小，成本占比更高，实际亏损更快。

## 六、关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| MACD跨日连续 | 是 | 日内EMA重置导致信号跳变，连续计算更稳定 |
| 标准化维度 | 时序（同时刻rolling20天） | 不同时刻因子分布不同，截面标准化会混淆日内规律 |
| IC类型 | 时序IC（组内择时） | T+0是同一股票日内择时，与截面选股IC不同 |
| 训练标签 | Walk-Forward历史分位数 | 避免当天组内排名依赖未来bar，与回测阈值逻辑对称 |
| 信号触发 | Walk-Forward历史阈值 | 绝对阈值 + shift(1)，实盘可直接部署 |
| 冷却期 | 6根bar（=1个持有期） | 防止持有期窗口内重叠建仓，避免虚假信号叠加 |
| 成本 | 15bps双边（含印花税5+佣金2.5+滑点7.5） | 保守估计，已在fwd_ret定义中扣除 |
